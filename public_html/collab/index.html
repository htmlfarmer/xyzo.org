how it works

  1. 1

    curl | bash

    install-collab.sh detects your OS, installs python3 if missing, generates an RSA keypair locally, and POSTs the public key to xyzo.org/api/collab/register.

  2. 2

    register

    xyzo returns a 12-char node_id + a 24-byte bearer token. Both are persisted to ~/.collab/config.toml with mode 0600.

  3. 3

    service installed

    macOS gets a LaunchAgent; Linux/WSL gets a systemd --user unit. Daemon restarts on crash, heartbeats every 30s.

  4. 4

    work starts

    Your node polls /api/collab/jobs, claims one, runs it in a sandboxed subprocess, and POSTs the result back. All visible on this dashboard.
